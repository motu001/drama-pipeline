# 漫剧完整制作流程

## 0. 初始化

确认素材来源、项目名、目标画风、单集时长和集数，建立 `script/`、`assets/`、`storyboard/`、`prompts/`、`video/`、`delivery/`，并写入 `pipeline.md`。

## 1. 剧本

按用户情况选择：现成剧本审计、小说/梗概原创改编、从一句话创作、90 秒精确时间轴、端到端短剧流水线，或原样使用现成剧本。剧本进入生产前检查因果、时长、人物动机、真人行为和台词通顺度。

## 2. 资产

先提炼视觉 DNA，再按需要制作角色设定/四视图、表情、动作、服装、道具、场景四视图、场景布局、俯视机位图或 VR 全景。图像生成后端由用户选择。未确认的参考图不得进入角色视频流程。

## 3. 分镜

根据目标时长选择快速故事面板、专业文字分镜、视觉九宫格、90 秒时间轴或视频拉片。每个镜头明确景别、机位、运动、角色位置、视线、动作触发—反应—结果和声音。

## 4. H3 提示词

先由 `manju-h3-production` 判断文戏/武戏，再由 `h3-prompt-writing` 组织 Ref2VA、T2VA、I2VA、FL2VA 或 L2VA。角色参考、场景参考和声线参考必须逐项对应；最终提示词先展示给用户确认，再进入生成。

## 5. 视频生成

用户选择 ComfyUI 本地、MiniMax API 或其他平台。ComfyUI H3 默认执行单段预检；在 16 GiB 显存环境使用 0.4 MP 母片，再放大到约 0.7 MP 交付画布。批量提交前再次确认数量和提示词版本。

## 6. 交付与学习

逐段核验分辨率、帧率、时长和音频流，整理命名并写交付 README。ComfyUI 后处理从 `*-audio.mp4` 开始，使用 `ffprobe` 确认 AAC。将新问题分为“已定位且已验证”或“仍待验证”，分别记录到 lessons/open-issues。

## 阶段门禁

- 没有用户选择，不自动跳到下一个阶段。
- 没有确认参考图，不生成角色一致性视频。
- 没有展示并确认提示词，不提交付费或批量生成。
- 没有单段预检，不提交整批。
- 没有交付核验，不宣称视频完成。
